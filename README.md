# The Royal Table — Premium Restaurant Website Demo

A premium, modern and responsive multi-page restaurant website created as a portfolio and client demonstration project.

## Overview

The Royal Table is a fictional premium family restaurant website designed to demonstrate how a modern restaurant can showcase its menu, ambience, offers, gallery, location and reservation options online.

The project focuses on elegant presentation, responsive design and a smooth user experience across desktop, tablet and mobile devices.

## Run Locally

No installation is required.

Open:

index.html

in any modern web browser.

## Pages

- Home
- About
- Menu
- Gallery
- Offers
- Reservations
- Contact
- Additional restaurant information pages

## Features

- Premium black + gold restaurant design
- Fully responsive layout
- Mobile-friendly navigation
- Multi-page website structure
- Menu category filtering
- Responsive food and restaurant gallery
- Restaurant offers section
- Reservation form with demo-only success message
- WhatsApp enquiry CTA
- Contact and location section
- Sticky navigation

- Clean and reusable styling
- Optimized layout for desktop, tablet and mobile

## Demo Disclaimer

This website was created as a portfolio/client demonstration project.

The Royal Table is a fictional restaurant. Restaurant details, menu items, prices, offers, testimonials, contact information and other operational content used in this project are demo content.

The reservation form does not submit information to a real restaurant backend.

## Customization

The website can be customized for a real restaurant with:

- Restaurant name and logo
- Brand colors
- Real menu and pricing
- Food photography
- Contact information
- Google Maps location
- WhatsApp number
- Reservation system
- Social media links
- Custom domain
